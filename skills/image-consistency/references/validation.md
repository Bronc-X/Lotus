# 验证范围与规则来源

Skill 版本：0.1.1。这是按用户要求封装的可复用执行工具，未取得跨客户真实生成的 VERIFIED 结论。2026-09-22 的接口脚本复用了单项目实测版本；2026-09-29 增加结果恢复和 SKU 门禁后，新版本只完成离线与本机回环测试，尚无新客户真实生成。完整图像到视频工作流的验证状态不随封装而升级。

## 既有真实样例

2026-09-14：同一组人物/商品两张参考，分别提交服务端标识 `gpt-image-2` 和 `gpt-image-2.5-flare`；每模型一次付费请求，均返回可解码的 1024×1536 PNG，未自动重试。

- image-2 样例 SHA-256：`2ca4481c6c82c792ef28f9a025e66495f63c0a308ec33b78cf2fea7a532620ee`。
- image-2.5 样例 SHA-256：`f1538106c845822be2e52703a4a7a33cb9fccc2718ca0838d3197dba7bd050cc`。
- 观察：两张均基本保留人物与商品主体；该次 image-2 的商品下摆和层次更贴近实拍，小型标签文字仍需复核。这不是整体模型排名或稳定成功率。
- 来源脚本 SHA-256：`40460c872e3788ef96acc76ff0f3f601c7e3fc670ccc3d40521fed44deccce65`。第一张运行时是较早脚本修订；第二张与后续离线回归使用最终脚本，不宣称第一张做过相同代码重放。
- 实际扣费、供应商底层权重身份、无参考分支、三参考分支、多人物、批量吞吐、新客户真实生成与视频均未验证。

原始客户照片、供应商站点、密钥、签名 URL、历史客户提示词和机器路径未导出。哈希仅用于将样例绑定到原有本地审计，不能代替拥有原图时的质量复核。

## 规则导出清单

| 导出规则 | 分类与来源 | 泛化依据 / 脱敏 |
|---|---|---|
| 双参考分别负责身份与商品 | 单项目 DEFAULT | 已有双参考实测；角色可迁移，客户身份/商品事实未导出 |
| 姿势图只负责姿势构图 | 单项目候选 DEFAULT | 历史流程模板；此 API 三参考质量未验证 |
| image-2 样例偏好、白底、1024×1536 | LOCAL_DETAIL | 仅记录观察，不设为全局模型/风格/尺寸约束 |
| 环境变量配置、单次 POST、唯一回执与恢复状态 | 已测试的脚本行为 | 随包离线测试；无服务商专用逻辑或真实凭据 |
| 项目隔离、授权范围、密钥不落盘 | 宿主安全规则 | 依据当前任务工作协议；不依赖多个项目来证明 |
| 视觉审核和代表样图后扩批 | 可配置流程 DEFAULT | 当前商品发布需求决定审核标准，不声称保证零漂移 |

没有将单项目经验标为经多项目证明的经验性 INVARIANT；没有伪造 VERIFIED 源工作流收据。结构检查与隔离离线执行只能证明打包/软件行为，不能替代另一企业的真实质量验收。

## 更新条件

2026-09-29 更新增加 `media_api.py recover`、私有恢复胶囊与 `sku_gate.py`。旧样图和旧哈希仍作为 2026-09-14 历史证据；新代码变更不能继承当时的真实供应商运行结论。原图/事实单审批、逐项审核和结果恢复的新软件行为已在离线环境验证，内容质量仍待具体客户实测。

更换模型、供应商、参考组合或关键参数后，先检查协议和代表样图；修改脚本后重跑受影响离线测试。保留失败样例与回执，根据实际证据修正规则，不把偶发结果升级成全局禁令。

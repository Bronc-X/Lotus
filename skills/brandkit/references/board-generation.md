# Brand board generation

Choose a board format based on the requested decision:

- Concept selection: one board per concept with mark, premise, palette, type, and two relevant applications.
- System review: an overview board plus focused boards for logo construction, color/type, imagery, and applications.
- Launch presentation: a small sequence that moves from premise to identity to real use.

Use a clear presentation grid, strong gutters, deliberate negative space, restrained labels, and a single visual hierarchy. Match the canvas ratio to the delivery context; do not force a fixed grid or dark background.

Prompt inputs should state:

- exact brand name and any text that must appear;
- audience, purpose, personality, and concept metaphor;
- mark type and construction logic;
- palette and typography roles;
- board format and requested applications;
- image or material direction;
- exclusions, especially copied logos, fake microtext, irrelevant mockups, and unreadable labels.

Generate requested concepts separately so one failed or inconsistent concept can be corrected without replacing the rest. Inspect the actual images for legibility, repeated mark consistency, panel alignment, unintended text, obvious artifacts, and brand coherence. Regenerate only the affected output.

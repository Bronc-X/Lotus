# Brandkit

Turn the brand brief into a coherent identity system and usable visual deliverables. Do not imitate an existing logo or claim trademark clearance.

## Route

- For strategy, logo concepts, color, type, and system rules: read [references/identity-system.md](references/identity-system.md).
- For image-generation prompts, identity boards, and application mockups: read [references/board-generation.md](references/board-generation.md).

Read both only when the request includes both identity design and generated presentation boards.

## Shared constraints

- Start from the brand’s audience, promise, personality, use cases, and practical constraints. When a missing choice would materially change the identity, ask one focused question; otherwise infer and state the assumption.
- Develop distinct concepts from a clear metaphor, not decorative variations of the same mark.
- Keep the logo reproducible at small size and across monochrome, light, and dark contexts.
- Use a controlled type and color system with accessible contrast for intended applications.
- Reuse the same mark, palette, type hierarchy, image treatment, and spacing language across delivered boards.
- Use short, legible labels. Generated imagery is a design direction, not a production-ready vector master.

Completion means the requested concept count and applications are delivered, the identity remains consistent across them, outputs have been inspected at useful sizes, and any generation or rendering failures have been corrected and rechecked.

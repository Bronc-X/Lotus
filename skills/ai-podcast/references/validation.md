# 验证范围

2026-09-23：此包按更新后的 Toni Voice、本人风格写作流程和已有多平台分发经验封装。不是对所有电脑、语言和平台完成一次新的端到端验收。

## 已实测

- Windows，PyTorch 2.8.0+cpu：使用现行 Toni profile，CPU float32 / 32 步生成 2.625 秒音频；脚本记录 77.562 秒（含加载等开销）。检查非静音、有限样本、24 kHz 单声道、无削波及产物哈希通过。这说明可以在 CPU 跑通，不能承诺实时生成。
- 同一 CPU 环境：从 9.9 秒人工原声片段和精确逐字稿创建新的候选 profile，保存原声与 prompt 的 SHA256；编码阶段 4.61 秒。未将此测试候选替代已批准 Toni。
- 新建候选 profile 再合成 2.614 秒短样成功（74.625 秒）；原现行 profile 的相同任务重跑返回 reused，输出哈希保持一致。
- 离线合同测试覆盖设备选择与显式设备不可用报错、镜头时长上限、设备变化不能复用旧指纹、发布文件篡改检测、不同账号/动作的授权不匹配。`python scripts/self_test.py`。
- Skill frontmatter/名称/结构用 skill-creator 的 quick_validate 检查。
- Lotus 的 PowerShell 与 Bash 安装复制函数在隔离目录实测：更新脚本同时保持私有 voice.pt、voice.json、runtime.json 字节不变；原同步测试扩展后通过，第二次同步不再改动。

## 验证边界

- MPS 路由基于 OmniVoice 官方源码；路由分支有模拟测试，未在 Apple Silicon/Intel Mac 实机生成音频。必须目标机 doctor/短样测速后才能宣称该机可用。
- 本次 CPU 短样是运行性与数值检查，不是用户对新设备听感的批准；中文短样不能证明英文质量或长稿无误。
- 文字处理是 Agent 工作流，不是纯脚本自动事实核查；需要遵循实际材料与用户目标执行。
- 分发流程未在本次 Skill 创建任务中真实上传；只有具体节目任务得到授权后才能执行并核验。发布包哈希测试不等于平台发布成功。
- 不使用 VERIFIED 标记代表全流程、所有平台或独立验收均通过。

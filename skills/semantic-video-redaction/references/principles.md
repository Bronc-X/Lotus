# 目标追踪原理

## 三种信息各自负责什么

语义检测回答“哪一片区域可能包含目标”，视觉细化回答“实际需要遮住的边界在哪里”，时序跟踪回答“这个目标在下一帧移到了哪里”。三者不能互相替代。本包内置 NudeNet 只给乳房等类别的矩形粗框，不提供乳头、乳晕专用分割模型；精准边界由执行 Agent 查看原帧后建立关键帧，再逐帧跟踪和复核。因此它是带视觉校正的流程，不是无人复核的全自动乳晕识别器。

## 模板跟踪

从已确认的关键帧截取目标纹理作为模板，在下一帧的局部搜索范围中计算归一化相关系数，选择最相似的位置。局部搜索约束减少跳到另一侧目标或背景的机会。位置在每帧根据图像重新计算，不是固定坐标。

纹理稳定时，这种方法精确且计算量小；遮挡、旋转、形变、光照改变或相似目标会使它失效。低分时脚本保留位置并记录问题，不能把这个保留位置当作检测成功。需要查看原帧、重新取模板或改用光流。

## 双向光流

光流从相邻两帧的局部亮度和纹理变化估计像素运动。本包用 Farneback 光流，在目标区域内取运动中位数，降低少量离群像素的影响。它不是人体解剖模型，也不认识乳头或乳晕。

在两个视觉确认的关键帧之间，从起点向后跟踪、从终点向前跟踪，再按帧位置融合两条轨迹。设相邻关键帧为 a、b，当前帧为 i，权重 u=(i-a)/(b-a)，融合位置为 (1-u)×前向位置+u×后向位置。融合的是从实际相邻帧计算出的轨迹，不是仅对起止坐标作直线插值。

前后向分歧和相对引导位置的漂移会被记录。漂移限制只能约束错误幅度，不能证明目标已被正确识别。手指可能带走跟踪点，完全遮挡后不存在可见纹理，此时必须依靠更密的视觉关键帧或分段处理，不能编造持续检测成功。

## 遮挡范围与复核

中心和半轴定义实际遮挡范围；乳晕不是一个中心点，应覆盖完整外缘。渲染同时保留当前帧范围，并参考邻近帧构造小幅运动余量，防止平滑导致遮挡滞后。遮挡在目标消失、重新出现或切镜时必须按连续轨迹分段，避免跨镜头沿用位置。

马赛克前的预模糊用于去掉可辨认细节，马赛克方块和边界余量随实际尺寸调整。对每条轨迹检查所有活动帧的原图轮廓，再检查所有导出目标帧；检测分数、轨迹连续和技术校验均不能单独证明无漏码。

复核页与片段、目标配置、轨迹和导出文件的哈希绑定，防止修改后沿用旧复核。这个记录只能证明检查对象的一致性，无法代替实际看图，也不是不可篡改的审计。

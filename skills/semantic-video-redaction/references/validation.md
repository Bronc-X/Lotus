# 验证范围

本 Skill 来自一次 8 秒医美视频打码执行。原执行用乳房语义粗定位、视觉校正关键帧、左侧双向光流和右侧模板跟踪，输出 1280×720、30 fps、240 帧、8 秒原声片段。执行 Agent 检查了逐帧目标范围和导出画面；用户随后要求封装 Skill，未单独给出成片视觉验收结论。

只将这一案例的做法作为默认路径。原片时间、坐标、左右侧命名、人物、路径及素材不进入通用配置。原执行中颜色分类受术前标记干扰的方案没有作为成功路径保留。

复现状态为 `LOCALLY_VALIDATED`，无最短或最优声明。打包前的实际回放、负向检查和独立测试摘要见 [validation-results.json](validation-results.json)。完整素材、任务日志、原图和含本机路径的记录留在原工作目录，不进入可迁移包。

实测平台是 Windows，Python 3.12，FFmpeg 8.1.2，NudeNet 3.4.2，ONNX Runtime 1.31.0 CPU，OpenCV 4.12.0.88，NumPy 2.2.6。脚本为 Windows/macOS/Linux 编写，但尚无 macOS/Linux 实机、不同 CPU 架构或无网络安装的执行证据。换机应重新检查环境、推理和短片导出。

已知边界：NudeNet 不直接分割乳晕；视觉细化和复核需要 Agent 的图像理解工具或操作者。切镜、完全遮挡、快速运动和外观大幅变化仍可能需要更多关键帧。逐帧复核记录属于本地可编辑收据，不是防篡改审计或“零漏码”的数学证明。

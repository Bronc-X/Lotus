# 打帧提示词

需要理解检测、视觉细化、模板和双向光流的分工时，读 [目标追踪原理](references/principles.md)。

先确定输入视频、截取时间、遮挡对象、输出位置。能从请求或视频安全检查确定的信息直接检查，不要求用户填写技术参数。首次使用或换电脑时读 [运行方式](references/runtime.md)；执行时读 [命令与坐标](references/commands.md)。可复制的调用提示词在 [assets/prompt.txt](assets/prompt.txt)。

## 识别与跟踪

1. `prepare` 精确解码指定时段，保留显示方向，建立片段、帧数和哈希，并逐帧运行本机语义模型。默认 NudeNet 3.4.2 的 `320n.onnx`，CPU 可运行，不需要 API Key。记录实际版本、模型哈希和执行提供程序。
2. 查看源图和关键帧。NudeNet 的 `FEMALE_BREAST_EXPOSED` 是乳房粗框，**不等于乳头、乳晕检测结果**。由视觉判断在粗框内标出完整乳晕的中心和遮挡半轴，保存本任务的 `targets.json`。同一画面中每个目标独立建轨迹；人数变化、出入画、切镜时分段。
3. 可见纹理稳定时用 `template`；有手指遮挡、提拉、形变时用有关键帧约束的双向 `flow`。初始可在每 0.3–0.5 秒及遮挡、放开、快速运动处建立关键帧，按实际结果加密。每一帧都产生位置和状态；不能用两端坐标直线插值冒充跟踪。
4. 检查原帧上的完整遮挡轮廓。发生语义漏检、模板低分、光流分歧或切镜时，保留问题帧和状态，增加视觉校正点或拆段；不可因为检测不到就取消打码。不能以乳晕肤色、性别猜测或人体整体框代替目标识别。
5. `review --stage tracks` 为每条轨迹生成覆盖每一帧的局部检查页。实际打开所有页，检查乳晕外缘、乳头、遮挡与放开处、首尾帧；必要时放大原图。确认后用 `approve` 记录已看的页面。此处是执行 Agent 的复核，不默认要求用户再次确认。
6. `render` 输出带原声的视频，默认粗马赛克加预模糊和小幅边界余量。再生成 `review --stage export`，实际检查每一帧的导出目标区域并登记复核。运行 `verify` 全片解码，检查帧数、时长、分辨率、音轨以及复核记录是否对应当前版本。通过后才交付。

## 完成边界

- 源视频不改动。时间、尺寸、帧率、目标数、坐标、关键帧、检测阈值、样式和路径均属于本次任务配置，不能复制上个视频的参数冒充识别。
- 检测置信度不代表遮挡完整；“两块码一直存在”也不证明没有漏出。技术校验和逐帧视觉检查都要完成。小目标必须查看局部检查页。
- 模型粗框可作为保守的临时遮挡；用户要求精准乳晕打码时，不能把整侧乳房打码当作完成。
- 紫色术前标记、肤色变化及手指可能干扰颜色分类。默认不采用本次曾失败的“只按肤色分类并取最大连通域”方案。模型或跟踪不可靠时使用视觉关键帧校正，仍不确定就明确报告卡点。
- 未经授权不上传原片、帧图或模型输入，不默认使用云端视觉服务。模型安装可以下载公开依赖；它不包含对外发送、公开发布或使用付费凭据的授权。
- 其他目标需有实际支持其类别的检测器或视觉定位证据。本包内置模型不提供任意文本目标检测；不得声称已自动识别其不支持的类别。
- 成片不加制作说明、水印、帧号、技术标签或检查页文字。检查材料留在工作目录，默认只交付视频。

## 适用证据

已在 Windows、Python 3.12、CPU ONNX 环境回放医美片段；跨系统代码使用相对资源路径和运行时参数。换电脑必须先诊断并做一次模型推理与短片导出检查。验证范围和已知限制见 [validation.md](references/validation.md)，不能把跨平台编写等同于已经在每种系统实测。
